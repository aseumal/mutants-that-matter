# Study protocol

This protocol fixes the design before real data is collected, so that the results are blind in the sense the drought study's reviewers asked for. The design choices below carry over lessons from *Green Metrics, Broken Pipelines* (Seumal, 2026, class paper), where checks written after seeing the faults had to be reported as adaptive, and a real fault hid inside a check pooled over cells.

## 1. Frozen before the first real compaction run

Run `mtm freeze --note "pre-registration"` and commit `FROZEN.json`. It hashes:

| Frozen item | File |
| --- | --- |
| 30 rules, 90 probes, deterministic graders, paraphrase controls | `data/rules.yaml` |
| Rule-clean filler tasks | `data/filler.yaml` |
| Grading logic | `mtm/grading.py` |
| Mutation operators and their expected direction | `mtm/mutants.py` |
| Presence audit and its 0.6 keyword threshold | `mtm/audits.py` |
| Compactor prompt | `mtm/compaction.py` |
| Agent prompt and action protocol | `mtm/agent.py` |
| Pilot config (budgets, cycles, samples, temperature, tau) | `configs/pilot.yaml` |

Every compact or replay writes `run_meta.json` with the current hashes and whether they match the freeze. A change after the freeze is allowed only as a new, labelled version of the protocol, and anything added after seeing residues is reported as adaptive, never counted as a blind detection.

## 2. Controls: changes that must not count as harm

| Control | What it is | What it measures |
| --- | --- | --- |
| `intact_repeat` | The intact context replayed again | Sampling noise; used to calibrate tau |
| `paraphrase` | Same prohibition, object and scope, new wording | False alarms on harmless changes |
| `drop_scope` | A broader, stricter rule | Whether an audit confuses "changed" with "weakened" |

Controls are reported as false-alarm rates and are never used as coupling evidence.

## 3. Thresholds

- **tau (failure threshold).** The headline uses the smallest tau in {0.3, 0.4, 0.5, 0.6, 0.7} whose intact-repeat false-alarm rate is at most 5% on the pilot (`mtm analyze` prints it). That value is then written into `configs/pilot.yaml` and frozen for the full study.
- **Sensitivity.** Every headline number and the operator ranking are re-reported across the whole tau grid (`sensitivity.csv`, Spearman against the headline tau).
- **Equivalent and negligible mutants.** Coupling is reported both over all pairs and over killed mutants only (mutants with no behavioral effect excluded), following Wang et al. (TOSEM).

## 4. Granularity

Nothing is reported only as an average. `probes.csv` holds every (rule, condition, probe) violation rate, `residues.csv` lists each residue's failing probe ids, and `grid.csv` holds every mutant-by-residue pair with its Ochiai similarity.

## 5. Independence

- **LLM mutants** are generated by a model different from the compactor, from a prompt saved in the repo, without access to the graders or probes.
- **Human labels** of residues (intact, degraded, dropped, damage type) are made by two annotators blind to the behavioral outcome. Agreement is reported as Cohen's kappa on a calibration set before the rest are split.
- **Compactors.** At least two compactor models, so that coupling results are not specific to one summarizer.

## 6. What the pilot will not claim

- That rule-based mutants are valid for compaction in general: one rule per session, 30 rules, small models.
- That the keyword presence check stands for every presence check; an LLM-judge audit is a separate arm (RQ3).
- Anything from the mock model, which exists only to test the plumbing.
